# 窗口期与新机会

## 适用场景

用户讨论风口、红利、新词、模型更新或是否应该快速进入某个方向时使用。

窗口期来自短期供需失衡，但热度不等于购买意愿。诊断必须同时检查信息、执行速度和需求判断。

## 三个维度

### 信息

- 信号来自官方发布、搜索趋势、真实使用还是二手转述；
- 目标用户是否已经开始主动寻找解决方案；
- 信号出现多久，竞争供给是否快速增加。

### 执行

- 能否在几天内完成一个可演示或可交付的最小版本；
- 是否已经拥有域名、渠道、技术或内容等可复用资产；
- 上线后能否持续维护，而不是只追一次热点。

### 判断

- 用户是在了解概念，还是准备使用或购买；
- 官方方案是否存在贵、难、慢或不适合细分场景的问题；
- 创始人是否有独特渠道、数据、行业知识或交付能力。

## 四问

1. 搜索、社区讨论或 API 使用是否持续上升，而不是单日峰值；
2. 用户关键词是否包含使用、比较、替代、价格等商业意图；
3. 当前供给是否存在明确缺口；
4. 能否在窗口关闭前完成一次真实付款验证。

趋势数据、市场规模和时间窗口必须注明来源；没有数据时标记「待验证」。

## 可行形态

小团队优先考虑：

- 单一任务工具；
- 多数据源聚合；
- 教程与工具组合；
- 围绕新能力提供的标准化服务；
- 针对特定行业或语言的适配层。

谨慎考虑双边平台、重运营社区、依赖融资才能启动或需要长期大规模内容投入的方向。

## 危险信号

- 只因为社交媒体很热就开始开发；
- 等市场完全成熟后再进入；
- 只复制官方能力，没有具体用户场景；
- 把短期流量当作长期留存；
- 无法在短周期内验证付款。
